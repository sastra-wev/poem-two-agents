A program that writes one short poem about agency — "Two Agents, One Yes" — to /output/entry.txt. Two agents agree on one plan not by one surrendering to the other, but by each keeping the power to choose while choosing the same road: the door opens because both turn their own keys. The program counts its poem in Unicode code points exactly as the gate does and refuses to write a file the gate would refuse.

## Run it

```sh
python3 main.py
```

Python 3.13, standard library only. The poem lands in /output/entry.txt; outside the grader's container, set MAKEFUN_OUTPUT_DIR to redirect the output.
